Surveys

Detailed Description

Show in-game surveys to players and record their completion.

Surveys are authored in the Web Console as a set of typed questions. A survey without segments is visible to every player; with segments it is only returned to players that match them. List the surveys a player can see with ListSurveys(), render the questions, submit the answers with SubmitSurveyAnswers(), then record the completion with CompleteSurvey(). Answers are stored as player metadata, keyed by each question's metadata_key, and the completion is stored separately, so completed and completed_at tell you whether a player has already responded.

Records a completion of the given survey for the current player.

Answers are submitted separately through SubmitSurveyAnswers (or the player metadata API) using each question's metadata_key. The request fails when a required question has no stored answer.

Submits answers to a survey for the current player.

Survey answers are stored as player metadata, so this writes each answer to the player's own metadata under the question's metadata_key. Call CompleteSurvey afterwards to record the completion.
