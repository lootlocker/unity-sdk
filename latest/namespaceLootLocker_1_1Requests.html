enum LootLocker.Requests.LootLockerConnectionState

The state of a player's connection and session with the LootLocker backend.

Returned by LootLocker.Requests.LootLockerSDKManager.CheckConnectionStatus.

Enumerator
NotInitialized 

The SDK has not been initialized.

NotSignedIn 

No session token exists for the specified player – they have not signed in.

SavedButInactive 

The player has saved credentials in local storage but is not currently active in the.

multi-player session. Call the appropriate session start method or MakePlayerActive to activate them before calling CheckConnectionStatus again.

SignedInAndConnected 

The session token is valid and the server is reachable.

SessionExpired 

A session token exists but the server returned 401 – the token has expired.

Banned 

A session token exists but the player is currently banned.

NoConnection 

The server could not be reached (no network, timeout, or status code 0).

ServerError 

The server returned a 5xx error, or an unexpected non-success status code.
